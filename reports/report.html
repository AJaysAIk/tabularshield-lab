Full findings and assumptions

TabularShield Lab — research report

Question and scope Can magnitude-table protection methods preserve useful totals while reducing selected disclosure indicators? This research prototype compares methods using public data.

Recorded experiment - 3 public datasets; 9 measure profiles. - 8,100 method/workload/seed evaluations, including scale ablations. - 30 paired key seeds in this run. Query families and parameters fixed in [protocol](../docs/protocol.json). - Numerical output SHA-256: 3122940b062fd8248f44172e611694b15dda7b6689e3010623a9adeed1b38191.

Results at delta = 0.20 Queries are macro-averaged within each dataset. WAPE is calculated on visible cells only. Coverage is separate so withholding is never rewarded as perfect accuracy. The risk proxy is the fraction of originally flagged cells whose published values remain within 5% of truth. It is not an estimated probability of re-identification. Empty risk denominators are N/A.

Adversarial checks Exact margins: In the recorded 3×6 wholesale table, 2 cells were initially flagged. An attacker using visible cells, nonnegativity and exact margins could reconstruct 2 primary cells exactly. Greedy complementary suppression added 5 suppressions; exactly recoverable primary cells afterward: 0. Margin withholding: False. This check is scoped to one two-dimensional table and the stated constraints, not arbitrary linked queries or background information.

Repeated identical queries: Across 200 random noise realizations, increasing repetitions from 1 to 1,000 reduced fresh-noise averaging RMSE by 31.1×. Fixed-key RMSE stayed constant. Both use the same lookup-noise distribution and scale. Fixed keys address this averaging attack only; they do not establish general confidentiality.

What a release user gains and loses Additional suppression prevents exact recovery of the 2 flagged cells under the tested constraints. It reduces available cell values from 16/18 (88.9%) to 11/18 (61.1%). Users lose 5 detailed values, or 27.8 percentage points of coverage, while row and column totals remain available. Compare this cost with the distortion introduced by perturbation before choosing a release method. The repository includes a release decision note with review questions and the underlying calculation.

Geographic strand 110 occupied half-degree grid cells from real GeoNames GB settlement coordinates. The primary symmetric 4-neighbour graph yields residual Moran's I = 0.0653, permutation p = 0.205 (199 permutations). Neighbour sensitivity k = 2/4/8 is recorded separately. These are exploratory diagnostics, without a multiple-testing claim. Point neighbours are not administrative polygon contiguity. Settlement populations can overlap and have mixed reference years; their sum is not a UK population estimate.

Interpretation and decisions 1. Suppression must be assessed with its publication coverage and margin constraints. A low direct risk proxy can coexist with exact reconstruction. 2. A public fixed key is suitable for reproducibility, not confidential deployment. A production key and release lifecycle need separate security design. 3. Capping trades reduced dominance for downward distortion. Compare the paired capping ablation rather than assuming it is beneficial. 4. Increasing perturbation changes the utility/risk proxy trade-off. No setting is called universally optimal or privacy-safe. 5. Integration evidence is a bounded read-only API demonstration. Actual Cantabular integration, calibrated disclosure policy and independent domain review remain future work.

Uncertainty The 95% t intervals describe variability across key seeds on fixed datasets and fixed queries. They are not population confidence intervals. Deterministic methods have zero seed variability. Queries share records and are not independent replicates. See [paired contrasts](paired_comparisons.csv), [raw evaluations](experiment_results.csv), [limitations](../docs/limitations.md) and [data profiles](data_profiles.csv).
