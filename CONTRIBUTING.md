# Contributing

Use public data only. Explain the research question, contributor unit, mathematical assumptions and intended outcome in each change. Add tests for defects or changed statistical behavior, run the fixed evaluation and document result changes. Keep negative controls in the report.

Review changes against four questions: Is the numerical result correct? Does the attacker model match the claim? Is usefulness measured fairly alongside withholding? Can another person reproduce and understand the result?

AI coding tools may be used, but contributors remain responsible for validating generated code, licensing, experimental interpretation and any claim of personal understanding. Do not fabricate peer reviews or research results. This repository welcomes independent review; no external review has been claimed.
